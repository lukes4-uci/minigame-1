# Minigame 1
## Devlog
A Scene can be considered the environment within which the game takes place, while GameObjects are elements within the game and Components are traits or attributes that those elements have. These attributes can be physical, like colour and texture, or behavioral, dictating how the element moves or interacts with other elements. For instance, the Scene "cat cafe" can have the GameObject "cat", which can have Components like "fur texture", "fur colour", "eat food", "purr", and "walk around".
